====================================================
PlugnPay Smart Screens v2 Module
Payment Module for WooCommerce — module v1.1.12 (2026-08-27)
====================================================

***** IMPORTANT NOTES *****
This module is provided "AS IS". Limited technical support assistance
will be given to help diagnose/address problems with this module.

This module redirects customers to PlugnPay hosted Smart Screens
(https://pay1.plugnpay.com/pay/). WooCommerce does not collect
sensitive payment data at checkout.

Requirements:
  - WordPress 6.0+
  - WooCommerce 8.0+
  - PHP 8.1+ (PHP 8.2+ recommended)
  - HTTPS on the storefront (required for checkout)

Authorization Verification Hash (SHA-256) is very highly recommended.
Enable it in this module and in PlugnPay Merchant Admin → Security
Administration.

Capture, void, and refund (when needed) are typically performed in
PlugnPay Merchant Admin.

These modules do not support WooCommerce Cart/Checkout Blocks yet.
Use classic checkout if Blocks causes problems.
***************************

To Install:

1. Preferred: In WordPress → Plugins → Add New → Upload Plugin,
   upload woocommerce_ss2_module_1.1.12_20260827.zip.

   Or unzip into wp-content/plugins/ so you have:
     wp-content/plugins/plugnpay-ss2-payment-gateway-for-woocommerce/...

   From this repo's development tree that is:
     WooCommerce/src/plugnpay-ss2-payment-gateway-for-woocommerce/
       → <shop>/wp-content/plugins/plugnpay-ss2-payment-gateway-for-woocommerce/

2. Activate "PlugnPay SSv2 Payment Gateway For WooCommerce".

3. WooCommerce → Settings → Payments → enable and configure:
   - Gateway Username
   - Authorization Hash (very highly recommended, SHA-256)
   - Authorization Hash Key (when hash is enabled)
   - Response Verification Hash Key (recommended)

   If Authorization Hash is enabled, matching settings must be enabled
   in PlugnPay Merchant Admin. Response Verification Hash is recommended.

4. Payment completion callbacks are accepted only from PlugnPay
   callback servers. Allow inbound HTTPS from:

     18.214.78.64
     52.3.174.161
     54.91.210.62
     69.18.198.4
     107.22.32.178
     3.210.249.25

   If the store sits behind a reverse proxy or CDN, configure the web
   server so REMOTE_ADDR is the original connecting IP (for example
   mod_remoteip or nginx real_ip). Do not trust X-Forwarded-For from
   the client. Developers can use the
   woocommerce_plugnpay_ss2_callback_source_ip filter after verifying
   a trusted proxy.

   Hidden POSTs from PlugnPay callback servers are sent to the
   WooCommerce order-received or pay page. Those pages return a full
   themed HTML document, which PlugnPay captures and echoes to the
   shopper. Do not point those URLs at wc-api.
