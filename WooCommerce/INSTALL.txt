====================================================
PlugnPay API Credit Card Module
Payment Module for WooCommerce — module v1.2.2 (2026-08-27)
====================================================

***** IMPORTANT NOTES *****
This module is provided "AS IS". Limited technical support assistance
will be given to help diagnose/address problems with this module.

Requirements:
  - WordPress 6.0+
  - WooCommerce 8.0+
  - PHP 8.2+ (PHP 8.3+ recommended)
  - HTTPS on the storefront (required for checkout)
  - PHP cURL

This module requires SSL and PHP cURL. WooCommerce collects credit card
information on your store's checkout pages. Authorization is performed
via PlugnPay's Remote API. Capture, void, and refund (when needed) are
typically performed in PlugnPay Merchant Admin.

Authorization Verification Hash (SHA-256) is recommended. Enable it in
this module and in PlugnPay Merchant Admin → Security Administration.

PCI: Collecting cards onsite increases PCI scope. For hosted (lower
PCI) checkout, use PlugnPay Smart Screens v2 (see INSTALL_SS2.txt).

These modules do not support WooCommerce Cart/Checkout Blocks yet.
Use classic checkout if Blocks causes problems.
***************************

To Install:

1. Preferred: In WordPress → Plugins → Add New → Upload Plugin,
   upload woocommerce_api_cc_module_1.2.2_20260827.zip.

   Or unzip into wp-content/plugins/ so you have:
     wp-content/plugins/plugnpay-api-cc-payment-gateway-for-woocommerce/...

   From this repo's development tree that is:
     WooCommerce/src/plugnpay-api-cc-payment-gateway-for-woocommerce/
       → <shop>/wp-content/plugins/plugnpay-api-cc-payment-gateway-for-woocommerce/

2. Activate "PlugnPay API Credit Card Payment Gateway For WooCommerce".

3. WooCommerce → Settings → Payments → enable and configure:
   - Gateway Account
   - Remote Client Password (required)
   - Authorization Hash (recommended, SHA-256)
   - Authorization Hash Key (when hash is enabled)

   If Authorization Hash is enabled, matching settings must be enabled in
   PlugnPay Merchant Admin.
